# UI prototype

Clickable prototype of the redesign. Open `index.html` in a browser, no build step.
Fake data throughout; real copy, real portrait, real project screenshots.

| File | What it is |
|---|---|
| `index.html` | The prototype (Cobalt, dark, low contrast, rounded: the saved look) |
| `h.html`, `i.html` | Same pages, alternate layouts (centred hero, bento project grid) |
| `screens/` | A screenshot of every page and state, for review and for Figma |

## What to try

- **Boot screen:** remove `?noboot`, or open `index.html` fresh in a new tab.
- **Sign in:** lock icon in the header, any username and password. You land on the home page.
- **Edit inline:** pencil and trash on every entry, `New entry` in the section headings, forms open in place.
- **Secret entry:** type `I L O V E U` at a human pace (a quarter to one second between letters), outside any input.
  The `Another new Secret?!` link appears in the header.
- **Appearance:** floating button above the footer. 31 palettes, light and dark, five contrast steps, fine-tune sliders.
- **Tooltips:** hover any icon, heatmap cell or uptime bar.

## Not real yet

Detector scores, contribution counts, uptime figures, messages and the music block are sample data.
The portrait and project screenshots are real; the sona and gallery images are placeholders.
